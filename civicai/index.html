From selected text to an editable draft.

CivicAI works directly in Chrome and Microsoft Edge, without sending selected text to an external AI service.

1

Select text

Highlight a civic issue described on a website, local news page, forum or social platform.

2

Analyze locally

Right-click and choose “Analyze with CivicAI” to open the side panel and run the model on your device.

3

Review the report

Review the category, urgency, possible recipient, missing details and report draft before using it.

A focused workflow inside your browser.

CivicAI stays out of the way until needed, then presents the analysis in a compact side panel.

Useful structure, without automatic decisions.

CivicAI organizes the information. You always review, edit and decide what to do with the result.

Issue classification

Identifies the most relevant civic category using multilingual semantic similarity.

Urgency and recipient

Estimates urgency and suggests a potential public authority to receive the report.

Missing information

Highlights details that may be useful before submitting the report through an official channel.

Fully editable draft

Creates a starting draft that remains fully under your control.

Multilingual interface

Available in English, Italian, Spanish, French and German.

Open source

Source code, dependencies, model information, privacy details and licenses are publicly available.

Selected text stays on your device.

The multilingual model and ONNX Runtime are loaded from local extension files. CivicAI uses no backend, analytics services, cloud AI APIs or user accounts.

Local inferenceNo trackingNo API keysNo host permissionsNo automatic submissions

Make civic issues easier to organize.

CivicAI does not publish or submit anything automatically. It analyzes text locally and prepares a draft you can review and edit before using.
