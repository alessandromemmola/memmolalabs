From selected text to an editable report.

CivicAI works directly inside Chrome and Microsoft Edge, without sending selected text to an external AI service.

1

Select the text

Highlight a civic issue described on a website, local news page, forum, or social platform.

2

Analyze locally

Right-click and choose “Analyze with CivicAI” to open the side panel and run the on-device model.

3

Review the report

Check the category, urgency, suggested recipient, missing details, and editable report draft.

A focused browser workflow.

CivicAI stays out of the way until you need it, then presents the analysis inside a compact side panel.

Useful structure, without automatic decisions.

CivicAI helps organize information. The user always reviews and edits the result before using it.

Issue classification

Identifies the most relevant civic category using multilingual semantic similarity.

Urgency and recipient

Estimates urgency and suggests a possible public recipient for the report.

Missing information

Highlights details that may be useful before submitting the report through an official channel.

Editable report draft

Produces a structured draft that remains fully editable and controlled by the user.

Multilingual interface

Available in English, Italian, Spanish, French, and German.

Open source

Source code, dependencies, model information, privacy documentation, and licenses are publicly available.

Your selected text stays on your device.

The multilingual model and ONNX Runtime are loaded from local extension files. CivicAI does not use a backend, analytics service, cloud AI API, or user account.

Local inference No tracking No API key No host permissions No automatic submission
