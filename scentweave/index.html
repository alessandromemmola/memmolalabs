Versions

Start for free.
Expand when you’re ready.

The free version lets you build your first canvas. A one-time Pro unlock expands your space, adds more photos, customization and export options.

Free

Free version

A simple way to discover whether ScentWeave fits the way you remember.

  • 10 starting memory nodes.
  • 1 photo per memory.
  • Up to 3 saved fragrances.
  • Up to 3 saved canvases.
  • Optional rewarded ads for extra nodes.
Pro

Pro version

For a more spacious and personal archive that can grow with your memories.

  • Unlimited memory nodes.
  • More photos per memory.
  • Unlimited saved fragrances.
  • Unlimited saved canvases.
  • Custom color palette.
  • Export .scentweave files.
  • Open exported files in Memmola Labs Viewer.
  • No mandatory ads.
