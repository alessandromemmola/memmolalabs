# Memmola Labs Viewer

Official desktop and web viewer for ImmoBit and AutoBit analysis files.

---

## Overview

Memmola Labs Viewer is a privacy-first companion application designed to open, inspect and compare files generated by:

* ImmoBit
* AutoBit

The Viewer works entirely on the user's device and does not upload files to external servers.

---

## Features

### Open Analysis Packages

Load and inspect:

* `.immobit`
* `.autobit`

packages exported from the official applications.

### Visual Reports

Display:

* Overall scores
* Detailed evaluations
* Notes
* Photos
* Charts and summaries

### File Comparison

Compare multiple exported analyses side-by-side.

Useful for:

* Property comparisons
* Vehicle comparisons
* Historical evaluations
* Decision support

### Privacy First

All processing happens locally.

* No user accounts
* No cloud storage
* No file uploads
* No personal data collection

---

## Supported Applications

### ImmoBit

Real estate evaluation and inspection assistant.

Export analysis packages and review them in the Viewer.

### AutoBit

Vehicle evaluation and inspection assistant.

Export analysis packages and review them in the Viewer.

---

## Technology

Built with modern web technologies and distributed as:

* Progressive Web App (PWA)
* Desktop application

The Viewer can operate offline once installed.
