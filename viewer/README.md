# Memmola Labs Viewer

Official privacy-first web and desktop viewer for files created by AutoBit, ImmoBit and ScentWeave.

---

## Overview

Memmola Labs Viewer is a local-first workspace designed to open, organize, inspect and compare files generated by:

* AutoBit
* ImmoBit
* ScentWeave

The Viewer works entirely on the user's device.

Files are processed locally and are not uploaded to Memmola Labs servers.

The Viewer can be used directly in the browser or installed as a Progressive Web App (PWA).

---

## Local Profiles

Memmola Labs Viewer supports multiple local profiles on the same device.

Each profile keeps its own:

* Files
* Evaluations
* Local archive
* Preferences
* Profile information

This makes the Viewer suitable for shared computers, for example:

* Multiple real estate agents
* Multiple vehicle professionals
* Families
* Couples
* Personal collections

---

### PIN Protection

Profiles can be protected with a local PIN.

The PIN is used to unlock the profile and authorize sensitive actions such as:

* Opening another protected profile
* Deleting a profile
* Changing another profile's avatar

PIN verification happens locally.

Memmola Labs does not receive or store profile PINs.

---

### Profile Avatar

Each profile can use:

* A custom avatar
* A personal image
* Initials as fallback

Images are stored locally with the profile.

---

## Local Storage

Viewer data is stored on the user's device.

The Viewer uses browser-local storage technologies such as IndexedDB to maintain profile archives.

This means that different browsers, browser profiles or devices do not automatically share the same data.

---

## Backup and Portability

To avoid losing local data when changing computer or browser environment, the Viewer includes backup and migration tools.

### Export Profile

Export a single profile and its local archive.

### Import Profile

Restore an exported profile on another compatible Viewer installation.

### Viewer Backup

Create a backup containing all Viewer profiles and their archives.

### Restore Backup

Restore the Viewer workspace from a previous backup.

These features allow users to move their local workspace without requiring a cloud account.

---

## Privacy First

Memmola Labs Viewer is designed around local processing.

* No Memmola Labs account required
* No cloud storage required
* No automatic file uploads
* No server-side analysis
* No profile synchronization
* No advertising tracking
* Local profile protection
* Local encrypted archive

Files and profile data remain on the user's device unless the user explicitly exports or backs them up.

## Browser and Desktop Use

Memmola Labs Viewer is distributed as:

* Web application
* Progressive Web App (PWA)

It can be installed on supported desktop systems and can operate offline after the required resources have been cached.

When the browser and installed PWA use the same browser profile and origin, they can access the same local Viewer storage.

Different browsers or computers maintain separate local archives.

---

## Security

Profile PINs and local encryption are designed to protect Viewer data from casual unauthorized access.

The Viewer is not intended to replace operating-system-level security.

A person with full control of the operating system, browser profile or local storage may still be able to manipulate local application data.

Users should also protect their computer with appropriate operating-system security.
