Come funziona Viewer
Guida rapida a profili, privacy, file e backup.
01 · Profili

Uno spazio separato per ogni persona

Ogni profilo mantiene separati i propri file AutoBit, ImmoBit e ScentWeave. È utile su computer condivisi, in famiglia o in piccoli team.

02 · PIN

Protezione locale

Il PIN serve per sbloccare il profilo sul dispositivo. Memmola Labs non riceve il PIN e non può recuperarlo. I dati archiviati dal Viewer vengono cifrati localmente.

03 · File

I dati restano sul dispositivo

I file vengono letti dal browser e salvati nello spazio locale del profilo. Non vengono caricati sui server Memmola Labs.

04 · Browser e app

Stesso dispositivo, stesso spazio locale

La versione browser e la PWA installata possono usare gli stessi dati quando appartengono allo stesso browser/profilo e allo stesso dominio. Browser diversi o computer diversi hanno archivi separati.

05 · Cambio computer

Esporta o crea un backup

  • Esporta profilo: trasferisce un singolo profilo con i suoi file cifrati.
  • Backup Viewer: salva tutti i profili e i relativi archivi in un unico file.
  • Importa/Ripristina: ricrea i dati sul nuovo computer.
06 · Sicurezza

Protezione pratica, non un account cloud

Il Viewer è progettato per scoraggiare accessi casuali e proteggere i dati locali. Chi ha controllo completo del sistema operativo o del profilo browser può comunque intervenire sullo storage locale.
